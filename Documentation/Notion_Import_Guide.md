# Notion 임포트 가이드

이 가이드는 `Phase0_Bug_Fix_Documentation.md` 파일을 Notion 페이지에 추가하는 방법을 안내합니다.

## 방법 1: 마크다운 직접 임포트 (추천)

1. Notion에서 "Claude Code와 Gemini cli를 이용한 3매치 프로젝트 리펙토링" 페이지를 엽니다
2. 페이지 내에서 `/import` 명령을 입력합니다
3. "Markdown" 옵션을 선택합니다
4. `Phase0_Bug_Fix_Documentation.md` 파일을 선택하여 업로드합니다
5. Notion이 자동으로 마크다운을 변환합니다

## 방법 2: 복사-붙여넣기

1. `Phase0_Bug_Fix_Documentation.md` 파일을 텍스트 에디터로 엽니다
2. 전체 내용을 복사합니다 (Cmd+A, Cmd+C)
3. Notion 페이지에서 붙여넣기합니다 (Cmd+V)
4. Notion이 마크다운 구문을 자동으로 해석합니다

## 방법 3: Notion API 사용 (자동화)

만약 Notion API 토큰이 있다면, 다음 스크립트를 사용하여 자동으로 업로드할 수 있습니다:

```bash
# package.json에 notion SDK 추가
npm install @notionhq/client

# 업로드 스크립트 실행
node upload-to-notion.js
```

## 서식 확인 사항

Notion으로 임포트한 후 다음 사항을 확인하세요:

### ✅ 확인할 것들

1. **제목 계층 구조**
   - `# Phase 0 완료` → Heading 1
   - `## 🐛 핵심 개발사항` → Heading 2
   - `### 버그 #1` → Heading 3

2. **코드 블록**
   - 모든 코드 블록이 C# 문법 강조로 표시되는지 확인
   - 인라인 코드 (백틱)가 올바르게 표시되는지 확인

3. **구분선**
   - `\large\color{Yellow}━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`
   - Notion에서는 이것이 일반 텍스트로 표시될 수 있으므로 수동으로 Divider 블록으로 교체하세요
   - 각 구분선을 선택하고 `/divider` 입력 후 Enter

4. **체크박스**
   - `- [ ]` → Notion 체크박스로 변환되는지 확인
   - Phase 1-6 로드맵의 작업 항목들 확인

5. **이모지**
   - 🐛, ✅, ❌, 📋, 🎯 등이 올바르게 표시되는지 확인

6. **테이블** (필요시 추가)
   - 비교 표는 Notion의 표 블록으로 변환 권장

## 추가 서식 개선 (선택사항)

### 콜아웃 블록 추가

중요한 정보를 강조하기 위해 Notion의 콜아웃 블록을 사용할 수 있습니다:

```
💡 교훈
Static Event는 편리하지만 관리가 어려움
→ Notion에서 이 부분을 선택하고 "/callout" 입력
```

### 토글 블록 사용

긴 코드 섹션을 토글로 숨길 수 있습니다:

```
"수정 전 코드" 섹션을 선택
→ "/toggle" 입력하여 토글 블록으로 변환
```

### 버튼 추가

Git 커밋으로 바로 이동하는 버튼을 추가할 수 있습니다:

```
"/button" 입력
→ 텍스트: "Git 커밋 보기"
→ 링크: https://github.com/[your-repo]/commit/06bd0b5
```

## 색상 및 스타일 가이드

Notion에서 다음과 같이 스타일을 적용하세요:

### 제목 색상
- **Phase 0 완료** → 초록색 배경
- **발견된 버그** → 빨간색 텍스트
- **수정 완료** → 초록색 텍스트

### 인라인 코드 강조
- `+=` → 빨간색 인라인 코드
- `-=` → 초록색 인라인 코드
- `OnEnable`, `OnDisable` → 회색 인라인 코드

### 텍스트 강조
- "메모리 누수" → **볼드** + 빨간색
- "수정 완료" → **볼드** + 초록색
- "Phase 1-6" → **볼드**

## 검증 체크리스트

임포트 후 다음 항목을 확인하세요:

- [ ] 모든 제목 계층이 올바른지 확인
- [ ] 코드 블록이 C# 문법 강조로 표시되는지 확인
- [ ] 구분선을 Divider 블록으로 교체했는지 확인
- [ ] 체크박스가 올바르게 변환되었는지 확인
- [ ] 이모지가 모두 표시되는지 확인
- [ ] 인라인 코드가 올바르게 표시되는지 확인
- [ ] 링크가 작동하는지 확인 (Git 커밋 등)
- [ ] 이미지나 다이어그램이 필요한 부분 확인
- [ ] 오타나 서식 오류가 없는지 최종 검토

## 문제 해결

### 코드 블록이 일반 텍스트로 표시될 때
1. 코드 블록을 선택
2. `/code` 입력
3. 언어를 "C#"로 선택

### 구분선이 텍스트로 표시될 때
1. 해당 줄을 선택
2. Delete 키로 삭제
3. `/divider` 입력하여 Divider 블록 추가

### 체크박스가 변환되지 않을 때
1. `- [ ]` 형식의 줄을 선택
2. `/todo` 입력
3. To-do 블록으로 변환
